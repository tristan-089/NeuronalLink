# NeuronalLink

> Projet Python consacré à l'exploration et à la compréhension des réseaux de neurones artificiels.

## 📌 Description

**NeuronalLink** est un projet Python ayant pour objectif d'explorer le fonctionnement des **réseaux de neurones artificiels** et les différents concepts qui permettent à une machine d'apprendre à partir de données.

Le projet cherche à privilégier la compréhension et l'implémentation des concepts plutôt que l'utilisation exclusive de bibliothèques d'intelligence artificielle de haut niveau.

## 🚀 Fonctionnalités

- 🧠 Création et utilisation de réseaux de neurones
- 🔢 Manipulation des calculs nécessaires au fonctionnement des neurones
- ⚙️ Configuration de la structure du réseau
- 📊 Entraînement et prédictions
- 🧪 Expérimentation avec différents paramètres

## 🛠️ Technologies utilisées

- **Python**
- Réseaux de neurones artificiels
- Programmation orientée objet
- Algorithmique
- Mathématiques appliquées à l'IA

## ⚙️ Installation

> ATTENTION : Si vous voulez essayer le code, veuillez le faire sur un ordinateur assez puissant avec une 
> carte gaphique NVIDIA compatible CUDA. Je déconseille fortement de faire cette tâche avec le processeur.
> 
>Series GeForce RTX 50, 40, 30, 20   
>Series GeForce GTX 16, 10

> 
> Veuillez noter que plus votre carte est puissante, plus l'apprentissage va vite.
> Je recommande une RTX 3060Ti 12Go au minimum pour éviter une attente parfois longue.
> 
> Veuillez aussi noter que vous pouvez aller dans train.py et modifier le nombre d'époques.


Cloner le dépôt :

```bash
git clone https://github.com/tristan-089/NeuronalLink
cd NeuronalLink
```

Créer un environnement virtuel :

```bash
python -m venv .venv
```

Activer l'environnement virtuel sur macOS/Linux :

```bash
source .venv/bin/activate
```

Sur Windows :

```powershell
.venv\Scripts\activate
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```

## ▶️ Utilisation

Lancer le programme avec :

```bash
python main.py
```

## Objectifs

Les principaux objectifs de **NeuronalLink** sont :

- Comprendre le fonctionnement d'un neurone artificiel.
- Comprendre comment plusieurs neurones peuvent être organisés en couches.
- Implémenter les concepts fondamentaux des réseaux de neurones en Python.
- Expérimenter avec l'apprentissage automatique.
- Approfondir mes compétences en Python et en algorithmique.
- Construire une base solide pour des projets d'intelligence artificielle plus avancés.
